**版本**：v1\.0 MVP
**日期**：2026\-05\-15
**核心定位**：以动态情绪 Icon 为核心、语音优先的轻量情绪陪伴 AI，通过多模态情绪识别实现精准、真诚、低成本的个性化夸夸

## 1\. 需求概述

### 1\.1 项目背景

当代年轻人普遍面临缺乏正向反馈、易陷入自我内耗的情绪痛点，现有 AI 夸夸产品存在三大核心问题：

1. 交互繁琐：依赖打字输入，无法快速释放情绪

2. 成本高昂：直接用多模态模型生成文本，Token 消耗是轻量方案的 10\-20 倍

3. 体验不稳定：多模态模型生成风格不可控，易出现油腻、跑偏的内容

### 1\.2 核心解决方案（工业界标准最佳实践）

**任务拆分架构**：

- 多模态轻量模型（豆包 4\.0 Lite）：仅负责**音频情绪识别 \+ ASR 转文本**，输出结构化标签

- 低成本文本模型（豆包 3\.5）：结合**情绪 \+ 文本 \+ 用户记忆**生成标准化夸夸文案

**核心优势**：

- 成本降低 18 倍（豆包生态）/74 倍（OpenAI 生态）

- 生成质量 100% 可控，统一夸夸风格

- 可扩展性极强，后续可轻松新增情绪标签和功能

### 1\.3 MVP 目标

1. 实现 \&\#34;按住 Icon 说话，立刻获得精准夸夸\&\#34; 的核心体验

2. 支持语音、文字、图片三种输入方式

3. 集成分层记忆管理，实现 \&\#34;越用越懂你\&\#34;

4. 单用户单次调用成本控制在 0\.002 元以内

### 1\.4 目标用户

18\-35 岁年轻群体（学生、职场人），需要即时正向情绪反馈、追求轻量化体验的用户

## 5\. 记忆管理集成（对接 Supermemory MCP）

### 5\.1 记忆更新触发时机

1. 每次聊天完成后，自动将用户输入和情绪存入短期记忆

2. 当情绪强度≥0\.8 时，自动将事件存入 Supermemory 长期记忆：

    ```bash
    /mem-add 用户在2026-05-15感到疲惫，原因是加班到很晚 --user {user_id} --meta {"category":"emotion","intensity":0.9}
    ```

3. 用户收藏夸夸时，提取用户偏好更新长期记忆

### 5\.2 记忆读取时机

每次生成夸夸前，调用 Supermemory 检索相关记忆：

```bash
/mem-search {用户输入文本} --user {user_id} --top 3
```
