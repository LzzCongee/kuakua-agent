# 夸夸Agent助手微信小程序 · PRD（MVP版）

## 1. 产品概述 (Product Overview)

### 1.1 产品名称
夸夸Agent - 你的专属正向能量助手

### 1.2 产品定位
一款**主动式、轻量级**的微信小程序，通过AI大模型为用户提供全天候、精准、高情商的正向夸赞与心理赋能。核心解决用户“需要打气时”、“想要被肯定时”、“记录高光时刻时”的情绪价值需求。

### 1.3 核心价值
- **主动陪伴**：打破传统APP被动使用模式，主动推送关怀，成为用户口袋里的“隐形夸夸搭子”。
- **精准赋能**：基于用户场景和个人特质，生成不油腻、不套路的真诚夸赞，重建自信。
- **低门槛体验**：基于微信生态，无需下载安装，下拉即用，降低用户决策成本。

---

## 2. 用户需求分析 (User Analysis)

### 2.1 目标用户画像
- **核心用户**：18-35岁城市青年（学生、白领、创作者）。
- **核心痛点**：日常压力大、容易内耗、缺乏正向反馈、需要情绪调剂、希望被肯定。
- **用户诉求**：
    1.  **主动触发**：不想自己找，希望有人定时来夸。
    2.  **场景化**：工作累了、恋爱甜了、搞钱顺了，需要特定场景的鼓励。
    3.  **收藏回血**：需要一个地方存放所有赞美，低谷时可回顾。

---

## 3. 核心功能需求 (Core Features)

本版本（MVP）仅开发**4大核心模块**，确保产品快速上线并验证核心价值。

### 3.1 主动推送模块 (The "Agent" Core)
*实现你要求的“主动推荐”*
- **定时推送**：
    - 早安（08:30）：推送一句充满元气的开启祝福。
    - 午间（12:30）：午餐/休息时的轻松调侃，缓解疲惫。
    - 睡前（22:00）：温柔复盘，肯定一天的努力。
- **触发规则**：用户首次授权订阅消息后，自动开启。

### 3.2 首页随机夸夸 (Home Screen)
*用户打开即用的核心入口*
- **每日一句**：首页居中展示一句AI生成的今日专属夸夸。
- **一键再夸**：首页底部设置大按钮“💖 再夸我一次”，点击即可刷新生成一条新的夸赞。
- **卡片式设计**：背景采用渐变色或治愈系图片，营造氛围感。

### 3.3 场景化夸夸库 (Scenario Library)
*满足用户特定时刻的需求*
- **分类入口**：提供4个核心分类入口，图标直观。
    1.  💼 **事业搞钱**：适合工作、面试、创业、搞钱时。
    2.  🌸 **颜值气质**：适合自拍、打扮、提升自信时。
    3.  ❤️ **甜蜜恋爱**：适合和伴侣相处、表达爱意时。
    4.  ✨ **日常治愈**：适合生活小确幸、坚持、心态调整时。
- **交互**：点击分类，弹窗生成对应场景的夸赞文案，支持**复制**和**收藏**。

### 3.4 夸夸历史墙 (Favorites Wall)
*记录高光时刻*
- **自动收录**：用户通过“收藏”按钮保存的夸夸，自动汇总于此。
- **回顾功能**：支持按时间线查看，支持**一键清空**。
- **回血机制**：页面设置“今日回血值”可视化图表，增强成就感。

## 4. 产品架构与技术方案 (Architecture & Tech)

### 4.1 技术选型 (极简可行)
- **前端框架**：微信原生小程序框架 (WXML + WXSS) 或 **UniApp**（推荐，兼顾未来跨端需求）。
- **后端服务**：轻量化方案（如云开发 CloudBase）或简单 Go/Node.js 服务。
- **核心AI能力**：
    - **模型选择**：接入 **通义千问 (Qwen)** 或 **GPT** 任一接口即可。
    - **Prompt设计**：核心在于约束模型输出“短、平、实、甜”的夸赞，避免废话文学。示例Prompt见附录。

### 4.2 接口设计 (API)
仅需3个核心接口：
1.  `GET /api/quotes/random?scene=all` - 获取随机通用夸夸。
2.  `GET /api/quotes/scene?type=career` - 获取指定场景（事业/颜值/恋爱）的夸夸。
3.  `POST /api/users/favorites` - 收藏/取消收藏夸夸。

## 7. 附录：AI Prompt 规范 (核心话术)

这是小程序的灵魂，直接决定用户体验。

### 7.1 通用夸赞 Prompt
> 你是一个高情商、温暖的年轻助手。请根据当前时间和用户状态，生成一句**不超过30字**的夸赞。
> 要求：
> 1. **真诚不油腻**，避免浮夸的排比句。
> 2. **具体**，不要只说“你很棒”。
> 3. **风格**：元气、积极、略带一点点幽默。
> 4. **输出格式**：直接输出文案，不要加任何前缀。

### 7.2 场景化 Prompt (以“事业”为例)
> 你是一个懂职场的暖心顾问。请为正在努力工作的用户生成一句**鼓励夸赞**。
> 要求：
> 1. 肯定用户的**付出**和**能力**。
> 2. 字数控制在20-25字之间。
> 3. 语气像好朋友在耳边说话。
> 4. 输出格式：直接输出文案。
