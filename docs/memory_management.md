# 一、专为夸夸助手定制的3层记忆管理（能直接落地）
## 第一层：短期会话记忆（Short-Term）
### 存什么
- 当前这一次打开小程序的**对话上下文**
- 用户刚刚说的话、选的场景、情绪
- 最近3条夸夸内容
### 怎么存
- 按`session_id`会话存储
- 存**原始对话+场景+情绪**
### 触发时机
- 用户发文字/选场景 → 立刻写入
- 关闭小程序 → 自动过期（2小时）
### 为什么要做（产品痛点）
1. 解决**上下文脱节**：用户说“再夸我一次”，AI知道上一句夸了什么
2. 避免**重复夸**：同一次会话不生成重复话术
3. 保持**语气统一**：同一次打开风格不变（温柔/元气）

---

## 第二层：用户偏好记忆（Working Memory / 核心层）
### 存什么（结构化JSON，最关键）
```json
{
  "user_id": "xxx",
  "prefer_scene": "career", // 最爱点的场景
  "prefer_style": "温柔治愈", // 喜欢的夸夸风格
  "user_tags": ["程序员", "熬夜", "努力"], // 自动提取标签
  "avoid_words": ["油腻", "夸张"], // 不喜欢的词
  "last_emotion": "tired" // 最近一次情绪
}
```
### 怎么存
- 存在用户表`user_profiles`，**永久保存**
- 每次交互自动更新权重
### 触发时机
- 收藏夸夸 → 更新偏好
- 频繁点某场景 → 更新最爱场景
- 对话中提取关键词 → 更新标签
### 为什么要做（产品核心壁垒）
1. **夸到点子上**：知道你是程序员，就夸“逻辑强、沉得住气”，不夸空话
2. **千人千面**：有人喜欢温柔、有人喜欢元气，记忆决定风格
3. **越用越懂你**：这是夸夸Agent≠通用ChatGPT的核心
4. **给Prompt提供弹药**：让生成内容100%贴合用户

---

## 第三层：高光里程碑记忆（Long-Term）
### 存什么
- 用户的**小成就、小骄傲、高光时刻**
- 例：“今天完成项目上线”“今天坚持跑步3km”
### 怎么存
- 简单文本列表，不用向量（MVP阶段）
- 按`user_id`关联
### 触发时机
- 用户主动说成就 → 自动提取
- 收藏的正能量句子 → 转为里程碑
### 为什么要做（产品情绪价值）
1. **夸得真诚不油腻**：夸“你完成项目超厉害” > 空泛的“你真棒”
2. **打造陪伴感**：AI记得你的努力，像真朋友
3. **形成产品记忆点**：用户会回来“让AI回忆我的高光”

# 二、为什么必须是这3层？（对应夸夸产品的4大核心体验）
1. **短期记忆 = 不让对话断片**
   没有它，用户说“再夸一次”，AI完全不知道上下文。
2. **偏好记忆 = 个性化夸夸的核心**
   没有它，所有用户夸法都一样，毫无竞争力。
3. **里程碑记忆 = 真诚感的来源**
   没有它，AI永远是套话机器人，无法打动用户。
4. **三层组合 = 低代码、低成本、体验拉满**
   不用向量、不用复杂算法，小团队100%能做完。

# 三、存储怎么做？（Supabase / CloudBase 最简方案）

- 有REST API，记忆队友可直接调用
- 支持权限控制，团队协作安全
- 免费额度足够MVP使用
