# 夸夸Agent API 功能接口文档

## 接口概览

本服务提供以下核心功能模块：

| 模块 | 路径前缀 | 功能说明 |
|------|----------|----------|
| 夸夸生成 | `/api/quotes` | 生成随机或场景化的夸夸文案 |
| 交互式夸夸 | `/api/chat` | 基于用户输入的个性化 AI 夸夸 |
| 收藏管理 | `/api/favorites` | 用户收藏的 CRUD 操作 |
| 健康检查 | `/health` | 服务状态查询 |

---

## 1. 夸夸生成 `/api/quotes`

### 1.1 获取随机夸夸

```
GET /api/quotes/random
```

**功能说明**：生成一条通用的随机夸赞文案，适合日常鼓励使用。

**请求参数**：无

**返回示例**：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "content": "你今天的状态真好，像阳光一样温暖！",
    "scene": "general",
    "created_at": "2024-01-15T10:30:00"
  }
}
```

**适用场景**：首页展示、"再夸我一次"按钮、日常打气

---

### 1.2 获取场景化夸夸

```
GET /api/quotes/scene?type={scene_type}
```

**功能说明**：根据指定场景生成相应的夸赞文案。

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| type | string | 是 | 场景类型 |

**场景类型**：

| 值 | 说明 | 适用场景 |
|----|------|----------|
| career | 事业搞钱 | 工作、面试、创业、搞钱 |
| beauty | 颜值气质 | 自拍、打扮、提升自信 |
| love | 甜蜜恋爱 | 和伴侣相处、表达爱意 |
| daily | 日常治愈 | 生活小确幸、心态调整 |

**返回示例**：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "content": "你的努力一定会有回报，继续加油！",
    "scene": "career",
    "created_at": "2024-01-15T10:30:00"
  }
}
```

**适用场景**：场景页点击分类、分类入口导航

---

## 2. 交互式夸夸 `/api/chat`

### 2.1 AI 交互式聊天

```
POST /api/chat
```

**功能说明**：接收用户发送的文字和/或图片，生成个性化的夸赞文案。支持三种输入模式：

- **纯文字**：用户分享心情、经历或想法 → AI 生成针对性夸赞
- **纯图片**：用户发送照片（如自拍）→ AI 看图生成夸赞
- **图文混合**：用户发送文字+图片 → AI 结合内容生成夸赞

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| text | string | 否 | 用户输入的文字内容 |
| image | string | 否 | 图片的 Base64 编码（可选） |
| scene | string | 否 | 场景类型（career/beauty/love/daily） |

**请求示例**：
```json
{
  "text": "今天完成了一个重要项目！",
  "scene": "career"
}
```

**返回示例**：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "content": "太棒了！完成重要项目的你真的很厉害，这种执行力值得骄傲！",
    "scene": "career",
    "has_image": false,
    "created_at": "2024-01-15T10:30:00"
  }
}
```

**适用场景**：用户主动分享经历、发送照片求夸、AI 看图夸

---

## 3. 收藏管理 `/api/favorites`

### 3.1 获取收藏列表

```
GET /api/favorites?user_id={user_id}
```

**功能说明**：查询指定用户的所有收藏记录，按创建时间倒序排列。

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | string | 否 | 用户标识（默认 "default"） |

**返回示例**：
```json
{
  "code": 0,
  "message": "success",
  "data": [
    {
      "id": 1,
      "content": "你的努力一定会有回报，继续加油！",
      "scene": "career",
      "created_at": "2024-01-15T10:30:00"
    }
  ]
}
```

**适用场景**：历史墙页面展示收藏的夸夸

---

### 3.2 添加收藏

```
POST /api/favorites
```

**功能说明**：为指定用户添加一条新的夸夸语录收藏。

**请求参数**：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| user_id | string | 否 | 用户标识（默认 "default"） |

**请求体**：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| content | string | 是 | 夸夸文案内容 |
| scene | string | 否 | 场景类型 |

**请求示例**：
```json
{
  "content": "你的努力一定会有回报，继续加油！",
  "scene": "career"
}
```

**返回示例**：
```json
{
  "code": 0,
  "message": "success",
  "data": {
    "id": 1,
    "content": "你的努力一定会有回报，继续加油！",
    "scene": "career",
    "created_at": "2024-01-15T10:30:00"
  }
}
```

**适用场景**：用户点击收藏按钮

---

### 3.3 删除单条收藏

```
DELETE /api/favorites/{favorite_id}?user_id={user_id}
```

**功能说明**：删除指定用户的特定收藏记录。

**路径参数**：

| 参数 | 类型 | 说明 |
|------|------|------|
| favorite_id | int | 收藏记录 ID |

**返回示例**：
```json
{
  "code": 0,
  "message": "删除成功"
}
```

**适用场景**：长按删除单条收藏

---

### 3.4 清空所有收藏

```
DELETE /api/favorites?user_id={user_id}
```

**功能说明**：删除指定用户的所有收藏记录。

**返回示例**：
```json
{
  "code": 0,
  "message": "清空成功",
  "data": {
    "deleted_count": 10
  }
}
```

**适用场景**：历史墙页面一键清空按钮

---

## 4. 健康检查 `/health`

```
GET /health
```

**功能说明**：查询服务状态，用于服务健康检查和监控。

**返回示例**：
```json
{
  "status": "healthy",
  "service": "夸夸Agent API",
  "version": "0.1.0"
}
```

---

## 统一响应格式

所有接口均返回以下统一格式：

| 字段 | 类型 | 说明 |
|------|------|------|
| code | int | 状态码（0 表示成功） |
| message | string | 状态信息 |
| data | any | 响应数据 |

```bash
uv run uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
